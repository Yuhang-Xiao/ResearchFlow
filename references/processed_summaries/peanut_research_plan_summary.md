## 研究主题

研究主题为“基于受限 POMDP 与深度强化学习的食品供应链风险暴露动态监管策略研究”。场景聚焦花生原料供应链中黄曲霉毒素 B1（AFB1）等霉菌毒素污染风险，在预算与抽检产能约束下，构建动态抽检资源配置与风险暴露降低策略。

## 花生/AFB1 风险监管背景

- 基于受限POMDP与深度强化学习的食品供应链风险暴露动态监管策略研究
- 基于受限POMDP与深度强化学习的食品供应链风险暴露动态监管策略研究
- 中国花生产业链长期面临黄曲霉毒素B1（AFB1）等霉菌毒素污染风险。现有风险评估研究表明，AFB1具有明确的遗传毒性与肝致癌性，且不同地区之间的膳食暴露水平存在显著差异(Benford et al., 2010; Wu, 2015)。在生产与储运过程中，污染往往与高温高湿、降雨季节等环境条件相关，导致其风险在时间与空间上有较大差异；例如针对长江流域花生的研究指出，当地较高污染率与其气候因素相关(Ding et al., 2015)。在这种高度异质的背景下，随机抽检很可能在多数时期得到较低检出，但这并不等同于风险被充分控制；食品安全标准体系也强调，仅依赖检测并不足以保证食品安全(Codex Alimentarius Commission, 2015; Jin et al., 2021)。同时，风险事件往往在首次被发现时已经扩散到更大范围，因此需要“尽早识别—及时处置”的资源配置(J. Wang et al., 2025)。
- 食品抽检不仅是对当期产品质量的检验，更是一种在不完全信息下配置有限监管资源的动态决策。当供给侧合规努力与真实污染水平难以被直接观察时，抽检提供了更新风险判断所需的信息，同时抽检的不确定性会影响供应商和采购方的行为，进而对食品安全产生影响(Starbird, 2005)，基于美国监管数据的研究发现，现场检查的结果能够对后续质量事件（如召回）给出有信息含量的预测，从而得出“检查—信息—未来风险”之间存在可建模的动态联系(Ball et al., 2017)。这类情境与部分可观测序贯决策相匹配：决策者无法直接观测系统状态，只能依据观测信号更新对状态的信念并据此选择行动(Monahan, 1982; Smallwood & Sondik, 1973; J. Wang et al., 2025)。同时，监管实践还必须满足预算与产能等硬约束，并在不同地区/对象之间做优先级排序与权衡(Van Asselt et al., 2021)，这与受约束MDP对“在约束条件下优化目标”的解释相一致(Altman, 2021)。

## 计数面板的数据结构要求

- 计数面板是后续 Beta-Binomial 信念更新、受限 POMDP / belief-MDP 与 DQN 动态决策的核心数据结构。
- 基本索引应优先为 `省份—月份—供应链环节`；月份不可用时退化为 `省份—年份—供应链环节`。
- 每个索引单元至少需要抽检总批次数、合格/不合格批次数、AFB1 相关记录数、AFB1 相关不合格批次数、浓度可用记录数和数据完整性标记。
- 本研究在理论建模与风险表征上实现了对传统监管优化问题的深化。针对真实污染水平对监管者而言不可直接观测的特性，本研究将抽检视为既提供观测信息以更新风险判断，又触发处置行动的复合过程，从而在“信念状态”上将该问题刻画为部分可观测的马尔科夫决策过程(Monahan, 1982)；同时，在优化决策处理上要求抽检批次的整数性与硬预算约束，从而把资源配置的可行性条件内生化到决策逻辑之中(Altman, 2021)。在风险刻画上，本研究将暴露评估与毒理学基准通过MOE/EDI进行对接，使监管目标从“提高检出”转向“降低暴露风险”，并与遗传毒性致癌物风险管理中常用的优先级讨论形成一致的度量基础(Benford et al., 2010; EFSA Scientific Committee, 2005)。在求解层面，针对省份与时间维度下高维信念状态和离散受限动作带来的计算瓶颈，采用深度Q网络进行近似动态规划，以函数逼近方式学习价值函数并从可观测特征生成抽检配置决策，为大规模受限POMDP在食品监管场景中的可计算化提供方法路径(Mnih et al., 2015)。
- 在信息不对称的市场环境下，抽样检验不仅是质量验证的手段，更是通过信息获取与激励约束影响供给侧行为的关键机制。Starbird（2005）基于委托—代理框架指出，由于抽样误差的存在，买方无法完全观测供应商的食品安全努力，这使得抽检强度与责任分担等制度安排不再是单纯的外生变量，而是与企业的质量投入水平通过策略互动形成内生关联。当企业将抽检风险与处罚后果纳入决策考量时，监管策略能有效改变其利益权衡，促使企业主动调整行为以降低风险，而非仅仅停留在发现当下的不合格产品(Starbird, 2005)。
- 食品安全抽检（监测）资源分配的核心难点在于：在预算受限条件下，决策者需要同时在采样位置、抽样策略、样本量与检测频次等多个维度上进行联合决策，并将监测表现明确映射到公共健康保护或风险降低目标上。现有研究通常将该问题形式化为预算约束下的优化设计，主要分为两类路径。一类研究侧重于“在给定预算下最大化监测绩效”，利用数学规划方法在供应链的多个控制点与多种危害之间分配检测资源。例如，Wang et al.(2020)在乳制品供应链多化学物质监测情景下，将各环节的样本收集与检测数量设为决策变量，采用混合整数非线性规划（MINLP）来最大化监测对健康风险（以伤残调整寿命年DALYs表征）的降低效果。另一类研究则强调不确定性与实施规则（如分层抽样、合并样策略）的组合复杂性，常将蒙特卡洛仿真与优化算法相结合，比较不同采样策略的成本效果，并输出不同预算水平下的最优方案(Focker et al., 2019; Powell, 2014)。此外，随着预测技术的发展，面向“高风险批次”识别的机器学习模型也被纳入监测流程，形成了“预测—抽检—成本”串联的决策框架(X. Wang et al., 2022)。相关研究进一步将风险监测流程结构化为“风险排序—抽样对象选择—抽样策略/样本量确定”三个步骤，这为将先进的优化算法嵌入抽检流程提供了逻辑思路(Focker et al., 2023)。

## Beta-Binomial 信念更新要求

- 观测信号来自每期抽检批次数与不合格/检出批次数。
- 对每个省份—环节维护 Beta 分布超参数，使用二项抽样观测进行共轭更新。
- 跨期传播应引入遗忘因子，使历史信息对当前风险保持适度衰减。
- 在食品安全监管的真实场景中，监管机构面临的首要结构性难题是信息的非完备性与状态的隐蔽性。由于受监管对象的真实污染水平（隐状态）无法被直接观测，监管者仅能通过抽样检验获取含有随机噪声的有限信号。针对这一特征，Smallwood与Sondik（1973）在有限视域下确立了部分可观测马尔可夫决策过程（POMDP）的最优控制框架。该理论证明，尽管物理状态不可见，但通过维护一个关于系统状态的概率分布（即“信念状态”），可以将原本不可观测的优化问题转化为信念空间上的完全观测问题，且其最优值函数呈现分段线性凸函数（PWLC）的结构特征(Smallwood & Sondik, 1973)。Monahan（1982）进一步从算法实现角度指出，信念状态构成了历史观测与行动的充分统计量。在这一框架下，抽检不再仅仅是判定合格与否的静态动作，而是既作为针对当期风险的直接控制手段，又作为动态的信息获取机制，通过贝叶斯更新修正后验概率以降低系统的认知不确定性(Kaelbling et al., 1998; Monahan, 1982)。因此，构建信念MDP（Belief-MDP）模型，能够为“观测—信念更新—动态决策”这一闭环反馈机制提供严谨的数学描述(Chadès et al., 2008)。
- 在此不完全信息结构下，监管者对风险的认知以信念分布（belief）而非点估计表述。具体地，对每个采用共轭的Beta–Binomial更新机制：在期初以表示对当期真实污染率的先验信念，当观测到后，后验仍为Beta分布并更新为。由此得到的后验均值与后验方差不仅提供了风险水平的可计算表征，该框架为不确定性的量化提供了统一的数学范式，使得抽检决策能够协同优化降低暴露风险与消解不确定性的双重目标{Citation}(Monahan, 1982; Spaan, 2012; J. Wang et al., 2025)。
- 考虑到食品安全风险具有显著的时间变动性（例如季节、仓储条件与气候冲击导致的非平稳），仅做严格累积的贝叶斯更新会使历史观测对当前信念的权重过强，难以及时反映结构变化。因此，在跨期传播时引入遗忘因子，将上期后验的强度按比例衰减后作为下一期先验，使信念既能继承历史信息，又能对近期变化保持敏感。通过上述“隐状态—观测—贝叶斯更新—遗忘传播”构造，原始的部分可观测过程可以转写为在信念空间上的马尔可夫决策过程（belief-MDP），从而为后续在预算与产能硬约束下求解动态抽检策略提供标准的序贯决策过程与可实现的统计更新路径(Altman, 2021; J. Wang et al., 2025)。

## DQN 动态监管优化要求

- DQN 不直接使用真实隐状态，而是在信念—风险特征空间学习政府抽检策略。
- 动作为跨省×环节的整数抽检批次数，需要离散档位、预算硬约束、产能上限和 action masking。

|  |  | 消费量：该区域的特定食品消费总量（若数据可得）。 | 市场数据 |

|  |  | 单位成本：各环节单次抽检的成本。 | 成本参数 |
|  |  | 产能上限：各省/环节的最大可抽检批次限制。 | 制度/物理约束 |
