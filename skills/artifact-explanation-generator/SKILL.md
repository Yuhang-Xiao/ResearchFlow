# artifact-explanation-generator

Mirror of `.agents/skills/artifact-explanation-generator`. Use for output explanation, figure/table/model/code explanation, and artifact-to-evidence mapping. Missing artifacts must be recorded as `unable_to_verify`; experimental outputs must not become formal claims. Explanations must be co-located with result directories; the total index is navigation only; key artifacts should have same-name `.explanation.md`.
