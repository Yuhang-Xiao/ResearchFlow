# Document-Governed Modeling

Before DQN/POMDP/belief-MDP/RL tasks, read the user research plan, model spec, project memory, processed summaries, and Zotero notes. User documents outrank Codex defaults and external methods.

Do not set formal state, action, reward, constraints, transition, or training hyperparameters unless the document specifies them or the user confirms them. Missing values must be listed in a parameter confirmation table.
