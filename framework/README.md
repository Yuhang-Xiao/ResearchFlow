# framework

This directory contains the public ResearchFlow OS framework assets:

- `model_registry/`: task, metric, validation, model, and explanation maps.
- `workflow_recipes/`: reusable workflow recipes and safety policies.
- `research_quality/`: publication and reproducibility quality policies.
- `workflow_improvement/`: safe self-improvement policies and ledgers.
- `templates/`: report and package templates.
- `prompts/`: launch prompts and prompt snippets.
- `reporting/`: public reporting notes that complement `src/workflow1/reporting/`.

These files are framework configuration, not private research output.
