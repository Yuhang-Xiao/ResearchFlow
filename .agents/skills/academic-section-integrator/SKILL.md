# academic-section-integrator

## Integration Contract

- Preserve source field names and verified numeric values.
- Align terminology across Introduction, Literature Review, Method, Results, Discussion, and Appendix.
- Insert figure/table references only for QA-passing artifacts.
- Keep citation read status visible in evidence tables.
- Preserve experimental/prototype/formal-ready boundaries.

## Outputs

- `full_paper.md`
- `section_crosswalk.csv`
- `integration_issue_log.md`
